# 一加 7T（hotdogb）+ 华为 VR Glass CV10 —— ALVR 改造工具包 v0.3

## 这个包针对 7T 做了哪些适配

| 项 | 7T 实际情况 | 包内对应处理 |
|---|---|---|
| CPU/ABI | sm8150 / arm64，但系统跑 32 位 App 兼容层 | runtime 编成 **ARM32 (armeabi-v7a)**，与原包 ABI 一致；姿态守护 `hwvrctl` 编成 **aarch64 静态**（root 侧跑） |
| GPU | Adreno 640，GLES 3.2 | runtime 报 GLES 3.0–3.2；swapchain 用 **RGBA8**（ALVR 硬要求） |
| 显示 | 眼镜 3840×1920 面板，单眼有效 1600×1600 | 视图/交换链按 **1600×1600 双目** 出，v0.3 合成 SBS 1600×3200 |
| 系统 | LineageOS 11，无 EMUI、无华为 VR 服务 | 删掉 `com.huawei.*` 权限；runtime 自给自足，不依赖 `/vendor/etc/openxr` |
| feature | 无 `android.hardware.vr.headtracking` | 清单改成 `required="false"`，不会挡安装 |
| 6DoF | 无麒麟 NPU → 华为 SLAM 不可用 | 眼镜走 **3DoF**；6DoF 做成"外部位置源喂 UDP 即生效" |
| SELinux | App 是 untrusted_app，读不到 `/dev/*`、`/data/local/tmp` | 姿态改走 **localhost UDP 47110**；节点由 root 侧模块创建并 `chmod 666` |
| 内核 | 4.14.190 仅编内核工程，不改 dtbo | 供电仍由 dtbo 的 `otg-cl-ua` 决定；本包不动内核 |

## 装什么、怎么装

### A. 只用 APK（推荐先试这个）
```bash
adb uninstall com.lht.huaweivr.alvr        # 签名已更换，必须卸载旧包
adb install -r 01-APP/HuaweiVRGlass-ALVR-7T-v0.3.apk
adb logcat -s MINIXR HVR-DIAG
```

### B. 加模块（拿姿态 + 建 /dev/hwvr1）
1. 把 `02-MODULE/01-alvr7t_runtime` 整个目录推到 `/data/adb/modules/alvr7t_runtime`
2. 把 `02-MODULE/02-hwvr_compat` 推到 `/data/adb/modules/hwvr_compat`（负责建 `/dev/hwvr0`、`/dev/hwvr1`）
3. 重启；检查：
```bash
adb shell cat /data/local/tmp/alvr7t_inject.log
adb shell cat /data/local/tmp/hwvr_pose
adb shell /data/adb/modules/alvr7t_runtime/bin/pose_probe
```
`pose_probe` 打 `[3DoF] q=...` 说明姿态链路通了；打 `[6DoF] q=... pos=...` 说明位置源也在。

### C. 想改包（重打包/重签）
```bash
# host 侧工具都在 03-TOOLS/host（apktool.jar / apksigner / zipalign + lib）
java -jar 03-TOOLS/host/apktool.jar d -f 01-APP/HuaweiVRGlass-ALVR-7T-v0.3.apk -o dec
# …改完…
java -jar 03-TOOLS/host/apktool.jar b -f dec -o unsigned.apk
03-TOOLS/host/zipalign -p -f 4 unsigned.apk aligned.apk
03-TOOLS/host/apksigner sign --key 04-SRC/signing/key.der --cert 04-SRC/signing/cert.pem --out out.apk aligned.apk
03-TOOLS/host/apksigner verify -v out.apk
```

## 当前能力边界（别误会）
- **已通**：OpenXR instance/system/双视图/GLES 要求/swapchain 格式、reference space/locate space/**locate views**、session(解析 GLES 绑定)、60Hz 帧节拍、swapchain 真纹理、**3DoF 姿态进了视图矩阵**。
- **未通**：EndFrame 的合成与呈现（要拿 `ANativeWindow` 做 SBS 输出）→ 所以现在画面还不会亮；输入 action 集也未做。
- 细节与验收点见 `05-DOCS/ALVR-7T-改造报告.md` 第 8 章。
